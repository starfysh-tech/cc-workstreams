workstreams mod · mock states v2

Personal Claude Code mod, loaded in every project. Reply by number, e.g. “3b: …”. Pink ◂ labels are annotations outside the UI. Sort order: APPROVE / PICK → YOUR TURN → REVIEW → WORKING → WRAP? / ORPHANED. Rows idle more than 7 days are dimmed. ↻ marks a row whose session is not running.

1. Toast overlay

No band above the prompt. When a workstream changes to needing you, a toast appears top-right over the transcript, where the panel would dock. It fades after a few seconds.

1a · toast appears

1b · after the fade

Nothing left on screen. The status line below the prompt is unchanged.

2. Panel open (^L) · hero

Panel docks on the right third, floor to ceiling. List → preview of the selected row → footer. Cursor on the PICK row. Esc closes.

Gauge colors: green below 60%, amber 60–85%, red above 85%. No version chip here because every session runs v2.1.295.
